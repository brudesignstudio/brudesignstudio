# 📸 Concept photos for the hero showreel

The mockup in the hero rotates through four example website styles. Each one uses a photo
from this folder. To swap a photo, just replace the matching file (keep the same name).
If a file is ever missing, that slide shows a colored background instead (no broken images).

| Filename | Slide | Industry |
|----------|-------|----------|
| `shot-barbershop.jpg` | "Ironside" | Barbershop |
| `shot-plumbing.jpg` | "FlowLine" | Commercial plumbing |
| `shot-travel.jpg` | "Wander & Co." | Travel |
| `shot-gym.jpg` | "Ironhaus" | Gym |

**Tips:** landscape orientation works best, roughly 1600px wide, JPG. The originals you
uploaded are still here too (the `... Website Example` files) in case you want them back.
